# Oguzki Support Copilot — запуск и сдача

Приложение сортирует обращения Grand Mobile и готовит ответ для сотрудника
поддержки. Начните с запуска без ключа: так можно проверить интерфейс, классификацию,
правила и черновики. Свою модель подключите вторым шагом.

## 1. Что понадобится

- Windows и установленный Python 3.11 или новее. При первой установке нужен интернет.
- Распакованная папка проекта. Не запускайте файлы прямо из ZIP.
- Два файла организаторов: `rules.json` и `taxonomy.json` из папки `handout`.
  Они не входят в архив решения. Для показа MVP датасет обращений не требуется.
- Для Gemini — собственный ключ Google AI Studio с доступом к модели
  `gemini-2.5-flash-lite`. Для локальных шаблонов ключ не нужен.

## 2. Запуск двойным щелчком

1. Откройте **START-MVP.cmd** в папке проекта.
2. При первом запуске дождитесь установки зависимостей.
3. Если появится `Folder path`, вставьте путь к папке, в которой лежат оба
   справочника. Например: `C:\Users\YourName\Downloads\handout`.
   Скрипт копирует только два справочника в `data/handout-2026-10-27/`.
4. Создайте логин. Для имени `admin` достаточно нажать Enter. Придумайте пароль
   длиной **от 15 символов**, введите его дважды. **Символы не отображаются:**
   просто печатайте или вставьте пароль и нажмите Enter. Если учётная запись
   уже существует, используйте свой прежний логин и пароль.
5. Выберите `2` или просто нажмите Enter для запуска **без внешней модели**.
6. После строки **Application startup complete** откройте
   [http://127.0.0.1:8001/](http://127.0.0.1:8001/). Войдите созданным логином.

Окно терминала нужно оставить открытым. **Ctrl+C** останавливает приложение.
При следующем запуске установки и создания учётной записи уже не будет.

Если двойной щелчок не работает, откройте PowerShell в папке проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\quickstart.ps1
```

Если Python установлен по нестандартному пути:

```powershell
.\quickstart.ps1 -PythonPath 'C:\Python312\python.exe'
```

## 3. Как вставить свой API-ключ

1. Остановите предыдущий запуск через Ctrl+C и снова откройте `START-MVP.cmd`.
2. При выборе режима введите **1** — Gemini.
3. Вставьте свой ключ в строку `Google Gemini API key` и нажмите Enter.
   Вставленный ключ не виден. Он передаётся только серверу и Google и не
   сохраняется скриптом в файл проекта.
4. После запуска обновите страницу. Выберите обращение и нажмите
   **«Проверить связь с ИИ»**. Эта кнопка делает один синтетический запрос,
   который может расходовать квоту и деньги. Затем можно использовать чат
   **«ИИ-помощник оператора»** и анализ обращения.

Надпись о наличии настройки означает только наличие параметров. Успешная
проверка связи означает, что модель действительно вернула допустимый план.
Ошибка модели оставляет безопасный шаблон. Классификация категорий работает
локально и не становится модельной от подключения ключа.

**Замена ключа:** остановите сервер, запустите снова и введите новый ключ.
Если ранее задавали `GEMINI_API_KEY` или `GEMINI_API_KEY_FILE` в окружении,
скрипт использует их без повторного запроса: обновите соответствующую переменную.
Ключи OpenAI и Google несовместимы; другой сервис требует своего адаптера.
Ключ не нужно вставлять в исходники, GitHub, браузер или присылать в чат.

Бюджет Gemini проверяется перед генерацией по числу токенов и тарифу.
Фактическая стоимость зависит от аккаунта и биллинга. Живые измерения модели
для этой сдачи пока не получены; подробности — в [ОТЧЁТ-ДЛЯ-СДАЧИ.md](ОТЧЁТ-ДЛЯ-СДАЧИ.md).

## 4. Быстрая проверка MVP

Дважды щёлкните **TEST-MVP.cmd**. Укажите справочники, если их ещё нет.
Скрипт сам поднимет временный сервер, проверит HTTP/CLI и остановит его.
Ключ и логин не требуются, внешняя модель не вызывается.

Успех: `PASS: HTTP/CLI, drafts and safety`. Отчёт появится в
`outputs/jury-check/summary.md`, подробности — `metrics.json` рядом с ним.
Проверка без приватных размеченных данных не вычисляет новую accuracy категории.

## 5. Что показать жюри за 3 минуты

Откройте [ДЕМО-ДЛЯ-ЖЮРИ.md](ДЕМО-ДЛЯ-ЖЮРИ.md). В панели используйте кнопку
загрузки тестового обращения или создайте новое с предложенным текстом.
Покажите очередь, исходный текст, категорию/приоритет, правила, редактирование
черновика, сохранение правки и эскалацию. «Отправить · MOCK» — демонстрационное
сохранение решения: реальной доставки в игру нет.

## 6. Частые проблемы

| Что произошло | Что сделать |
|---|---|
| Пароль/ключ не печатается | Ввод скрыт. Введите вслепую и нажмите Enter |
| `Port 8001 is busy` | Остановите старое окно через Ctrl+C либо запустите `.\quickstart.ps1 -Port 8002` и откройте порт 8002 |
| Не найден Python | Установите Python 3.11+ или передайте `-PythonPath` |
| Не найдены справочники | Выберите распакованную папку с `rules.json` и `taxonomy.json`, а не ZIP и не датасет |
| Существующий справочник отличается | Проверьте версии вручную; запускатель не заменяет другой файл молча |
| ИИ не настроен | При запуске выберите 1 и введите действующий ключ |
| Ключ отклонён / квота / модель недоступна | Проверьте проект и квоту Google AI Studio; подробный код покажет кнопка проверки связи |
| Слишком долгий ответ ИИ | Сервис использует безопасный шаблон; проверьте сеть и повторите синтетическую проверку |
| Не помню пароль | Владелец локально выполняет `.venv\Scripts\python.exe -m support_copilot.manage_operators reset-password --username admin` |

Технические команды API и пакетного запуска: [API-И-ПАКЕТНЫЙ-ЗАПУСК.md](API-И-ПАКЕТНЫЙ-ЗАПУСК.md).
Полные ограничения, происхождение метрик и требования: [docs/core-audit.md](docs/core-audit.md).
