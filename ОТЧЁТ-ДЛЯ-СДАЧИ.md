# Отчёт для сдачи — Oguzki Support Copilot

Сдаваемое ядро: HTTP `POST /triage`, пакетный `make predict`, интерфейс оператора, отчёт и демонстрация.

## Критерии с карточки кейса

| Критерий | Вес | Что сдаём / статус |
|---|---:|---|
| Качество черновиков | 30% | Контролируемые шаблоны и валидируемые планы модели; слепая оценка людьми ещё не получена |
| Классификация | 25% | Категория 76% на dev (актуальный прогон — [docs/core-audit.md](docs/core-audit.md); 71% в REPORT.md — более ранний прогон); accuracy приоритета 82%, macro-F1 всех 4 классов 0,5824 |
| Без выдуманных правил | 20% | Проверка ID, точности цитат и релевантности; 133/133 и 270/270 offline safety; на dev 2 цитаты, несуществующих ID 0 |
| Казахский и узбекский | 15% | Локализованные черновики, тесты нормализации; оценка носителями ожидается |
| Стоимость и задержка | 10% | Template: 0 внешних вызовов, API $0; localhost HTTP p95 169,84 мс на 200 запросах / 4 клиентах. Живой Gemini не измерен |

## Как получены числа

100 ранее размеченных человеком dev-обращений уже использовались для настройки: категория 76% (95% CI 67–84%), язык 94% (89–98%), приоритет 82% (74–89%). Это не независимый тест. Baseline большинства по kind — 53% на этой же выборке. Control в текущей итерации для инференса не использовался.

Обязательная эскалация: 65/65; доля needs_human — 100%, precision эскалации — 65%. Автоматическая разгрузка на dev не доказана. В dev нет p0, только 5 KK и 16 UZ случаев; качество критичных приоритетов и языковых черновиков по этим цифрам не устанавливается.

Полный локальный pytest: 739 passed, 1 optional skipped на версии ядра до добавления упаковки сдачи. HTTP/CLI совпали 20/20. Детали: [docs/core-audit.md](docs/core-audit.md). Общий балл жюри неизвестен: отсутствуют человеческие оценки и измерения живой модели.

## Стоимость

В шаблонном режиме оплачиваемого API нет; стоимость CPU и хостинга не измерена. Для Gemini добавлен token-count preflight и лимит выхода с бюджетом $0.002 по сохранённому тарифу. Это фильтр до генерации, а не подтверждение фактического списания. Timeout не считается бесплатным запросом. Собственный ключ вводится локально; проверка связи и модельные вопросы могут расходовать квоту.

## Примеры черновиков

Ниже — ответы на рукописные синтетические входы, полученные офлайн. Они не являются независимыми оценками качества.

### Русский

Вход: Застрял в текстурах

Язык: ru; категория: report.help; needs_human: false.

Что вы делали перед проблемой, что ожидали и что произошло? Повторяется ли ошибка?

На каком сервере это произошло?

Мәселе алдында не істедіңіз, не күттіңіз және не болды? Қате қайталана ма?

Бұл қай серверде болды?

### O‘zbekcha

Muammodan oldin nima qildingiz, nima kutgandingiz va nima yuz berdi? Xato takrorlanadimi?

Bu qaysi serverda yuz berdi?

## Устойчивость пакетного запуска (31.10)

`make predict` принимает как контракт `{kind, messages}`, так и сырой формат обращений
организаторов: `ticket_id` переносится в каждую строку выхода, ответы администратора и всё
после них не подаются в анализ, `images_count` учитывается как количество вложений.
Некорректная строка не останавливает прогон: для неё возвращается консервативный ответ
с `needs_human=true` и причиной `invalid_input_line`. HTTP `/triage` без настроенного токена
работает без авторизации на loopback.

## Запуск и проверка

1. Открыть `НАЧНИ-ЗДЕСЬ.md` и запустить `START-MVP.cmd`.
2. Указать папку с rules.json и taxonomy.json, создать свой логин.
3. Выбрать локальные шаблоны или ввести собственный Google Gemini API-ключ.
4. Запустить `TEST-MVP.cmd`; изучить outputs/jury-check/summary.md.
5. HTTP и make predict: `API-И-ПАКЕТНЫЙ-ЗАПУСК.md`. Показ: `ДЕМО-ДЛЯ-ЖЮРИ.md`.

Датасеты, ключи, локальные базы и справочники организаторов в архив и Git не включены. Для боевой игры доставки нет: действия отправки помечены MOCK. GitHub CI для проверенной версии заблокирован проблемой платежей/лимитом аккаунта владельца, локальные результаты его не заменяют.
