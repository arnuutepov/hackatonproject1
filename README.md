# Oguzki · Support Copilot

## Актуальное состояние: Wave 3 — черновики с проверкой источников

Анализ Wave 2 дополнен структурированным планом ответа, проверкой цитат,
политики эскалации и локализованным черновиком. Без ключа работают безопасные
шаблоны; внешняя модель подключается явно через Responses API. Произвольный
текст модели не пересылается игроку: итог собирается из контролируемых формулировок.
Полный статус и ограничения: [docs/wave-3.md](docs/wave-3.md).
Исходный baseline: [docs/wave-2.md](docs/wave-2.md).
Историческое описание Wave 0/1 ниже сохранено как контекст; оно не описывает
текущий `/triage`. Для Windows: `./run.ps1 -Install`, затем `./run.ps1`.
Swagger: http://127.0.0.1:8000/docs. Проверка: `./run.ps1 -Mode Test`.

Для запуска нужны локальные `data/handout-2026-10-27/rules.json` и `taxonomy.json`
из разрешённого архива организаторов. Они не входят в Git. Тесты также
используют эти источники. Для `-Mode Evaluate` восстановите канонические dev/control
файлы по путям из `evaluation/frozen-inputs.json`. В Git хранятся только хеши
и протокол оценки; реальные данные, разметка и локальные результаты не загружаются.

`draft_available=true`: возвращается проверенный план или безопасный шаблон.
Различие видно в `draft_reply.provenance`: `validated_model_plan` / `safe_template`.
`confidence` остаётся некалиброванной эвристикой анализа, не оценкой качества
черновика. `retrieved_rules` — кандидаты поиска, а не подтверждение нарушения.

Проверка без модели: `./run.ps1 -Mode DraftEvaluate` или
`python -m support_copilot.evaluate_drafts --output outputs/wave-3/synthetic-safety.json`.
175 тестов и 133 синтетические проверки прошли; живых вызовов модели — 0.
Синтетические примеры RU/KK/UZ: `examples/wave3_synthetic.jsonl`.

Модель выключена по умолчанию (`COPILOT_DRAFT_PROVIDER=template`). Чтобы подключить
её позже, задайте в окружении `OPENAI_API_KEY`, `COPILOT_MODEL` и
`COPILOT_DRAFT_PROVIDER=responses`, затем перезапустите сервис. `.env.example` —
справка; `.env` не читается автоматически. Никогда не добавляйте ключ в Git.

Вызовы API, качество живой модели и независимая языковая оценка не проверялись:
по выбору пользователя эта итерация полностью офлайн.

## Историческая справка Wave 0/1

Кейс 03 Grand Mobile × Decentrathon 6.0: ассистент поддержки и разбора жалоб.

**Wave 0 закрыт технически; инструменты Wave 1 готовы.** Работают HTTP, JSONL,
аудит и подготовка данных. Dev-разметка подтверждена пользователем; для control
подготовлены предварительные метки ассистента. Независимая человеческая проверка
control ещё не выполнена — [статус и ограничения Wave 1](docs/wave-1.md). Классификация,
определение языка, RAG, генерация и дедупликация ещё не реализованы. Все обращения
получают `needs_human: true`, `confidence: 0`, `category: unclassified`.
`priority: p2` и `is_spam_or_duplicate: false` — технические значения заглушки, не результат анализа.
`lang: und` обозначает отсутствие определения языка; текст заглушки на русском.
Категория `unclassified` временная и должна быть заменена значениями реального taxonomy.json.

## Запуск

Нужны Python 3.11+ и GNU Make. Проверено на Python 3.13.

```bash
make install
make test
make serve
```

Сервис: http://127.0.0.1:8000 · Swagger: http://127.0.0.1:8000/docs.
API-ключи, платные сервисы и датасеты для Wave 0 не нужны.
`.env.example` содержит только резервную настройку; сейчас приложение её не читает.

```bash
curl http://127.0.0.1:8000/health
curl -X POST http://127.0.0.1:8000/triage \
  -H 'Content-Type: application/json' \
  -d '{"kind":"report","messages":[{"role":"player","text":"Застрял в текстурах"}]}'
```

## Пакетный запуск

```bash
make predict IN=examples/synthetic_tickets.jsonl OUT=outputs/pred.jsonl
```

Одна строка входа — один JSON-запрос по HTTP-контракту. Одна строка выхода — один
ответ в том же порядке. UTF-8, без пустых строк. Ошибка формата завершает команду
ненулевым кодом, указывает номер строки и сохраняет предыдущий выходной файл.
Успешный запуск заменяет указанный OUT целиком. Вход и выход не могут совпадать.

Полные training/validation-записи не принимаются непосредственно `make predict`:
используйте адаптер Wave 1 ниже. Ответы `admin`, `verdict`, `punishment`, `violation` нельзя передавать
модели как признаки нового обращения. Дополнительные поля отклоняются.

## Wave 1: локальная подготовка данных

```bash
make audit-data IN=data/handout-2026-10-27/tickets_train.jsonl.gz OUT=outputs/train-audit.json
make prepare-data IN=data/handout-2026-10-27/tickets_train.jsonl.gz OUT=outputs/wave1-run-01
make predict IN=outputs/wave1-run-01/dev.inputs.jsonl OUT=outputs/dev-pred.jsonl
```

Архив организаторов получен отдельно от ТЗ и распакован локально в
`data/handout-2026-10-27/`. Метки category/priority в нём отсутствуют. Подготовка исключает ответы администратора и последующие реплики,
разделяет связанные группы по игрокам и точным повторам, создаёт отдельные
карточки ручной разметки. Всё остаётся в игнорируемых каталогах.
Нормализация казахских замен включается явно флагом `--repair-kazakh`.
Проверка пересечений, формат таксономии, разметка и ограничения описаны в
[инструкции Wave 1](docs/wave-1.md).

## Структура

```text
support_copilot/
  schemas.py    # вход и выход Pydantic
  service.py    # единое ядро, пока явная заглушка
  api.py        # FastAPI: /health и /triage
  cli.py        # JSONL через то же ядро
  dataset.py    # audit / prepare / compare / validate-annotations
  normalization.py  # оригинал + NFC, необязательные контекстные замены KK
tests/          # контракт, ошибки, отсутствие утечки меток, одинаковый HTTP/CLI
examples/       # только вымышленные обращения
docs/requirements.md  # требования, этапы и неясности ТЗ
```

## Данные и ограничения

Реальные выгрузки и производные выборки не публикуются даже в этом приватном
репозитории. Храните их локально в `data/`, результаты — в `outputs/`, ключи —
в `.env`. Эти пути исключены из Git. Примеры в `examples/` написаны вручную и
не взяты из данных Grand Mobile.

Количество вложений не означает, что сервис просмотрел доказательства:
в текущем ответе `has_evidence: false`, список цитат пустой. Заглушка не
устанавливает нарушения и не обещает наказаний, возврата денег или разбана.
Не используйте Wave 0 для автоматической отправки ответов игрокам.

Качество, стоимость и p95 пока не измерены. Настоящие правила, таксономия,
языки и политика эскалации появятся в следующих waves.

## Зависимости

`requirements-dev.lock` фиксирует версии зависимостей для воспроизводимого
окружения разработки. Make использует `.venv/bin/python`; при готовом окружении
можно переопределить `PYTHON=/path/to/python`. Без Make выполняйте команды
из целей Makefile напрямую; на Windows путь к Python — `.venv/Scripts/python.exe`.
