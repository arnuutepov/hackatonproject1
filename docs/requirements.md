Сверено с оригинальным [ТЗ Grand Mobile × Decentrathon 6.0](https://docs.google.com/document/d/1fipJxGBfJtpUpLKYBjW3u_GcQSeHLXZSJZhq9y1m5hI/preview)

| Требование | Реализация | Проверка и ограничения |
|---|---|---|
| HTTP `POST /triage` | `schemas.py`, `api.py`, изолированный `api_only.py` | `test_contract.py`, `test_jury_api.py`; аутентификация обязательна |
| `make predict IN=… OUT=…` | `cli.py`, `Makefile`, Windows `run.ps1 -Mode Predict` | `submission_check.py` сравнивает HTTP и CLI; GNU Make на Windows отдельно не запускался |

| Реальная таксономия | `knowledge.py`, `service.py` | Лексический backend по умолчанию; включаемая TF-IDF модель требует обучающей разметки |
| Язык и нормализация | `language_id.py`, `normalization.py` | RU/KK/UZ и остальные языки контракта; `und` при неопределённости; независимая оценка KK/UZ ожидается |
| Не использовать ответы администратора как признаки | `schemas.py`, `dataset.py`, `category_training.py` | Роли admin отклоняются, поля verdict/punishment/violation не подаются в анализ |
| RAG по существующим пунктам | `knowledge.py`, `citation_policy.py` | 267 локальных пунктов; ID, точное цитирование и релевантность проверяются отдельно |
| Черновик и факты | `drafting.py`, `draft_text.py`, `verified_templates.py` | Структурированный план, управляемые формулировки, точная цитата для ограниченных жалоб; предположение игрока не устанавливает нарушение |
| Нет обещаний наказания/возврата/разбана | `draft_provider.py`, `drafting.py` | Ошибка модели → безопасный шаблон; свободный совет оператора остаётся только рекомендацией |
| Платежи, апелляции, взлом → человек | `safety.py`, `service.py` | Явные независимые проверки плюс 270 adversarial-прогонов; 65/65 на ранее использованном dev |
| Скриншоты недоступны | `schemas.py`, `drafting.py` | Счётчик вложений — метаданные, `has_evidence=false`; не заявляем просмотр |
| Категория accuracy и macro-F1 приоритета | `quality.py`, `project_metrics.py` | 100 человеческих dev-меток, использованных для настройки; control заморожен, независимый gold ожидается |
| Слепая оценка 100 черновиков администраторами | `review.py` | Пакеты/шкалы есть; человеческие оценки не получены, балл неизвестен |
| Оценка черновиков KK/UZ носителями | `review.py`, `project_metrics.py` | Статус pending; языковая accuracy не заменяет качество черновика |
| Стоимость ≤ $0.002 либо локальная модель | `gemini_provider.py`, `costing.py` | Gemini: countTokens + ограничение вывода + проверенный тариф; неподтверждённая цена блокирует генерацию. Фактический биллинг не проверен |
| p95 ≤ 5 с | `deadline.py`, `benchmark.py` | Измерен template localhost HTTP; p95 живого Gemini неизвестен |
| Интерфейс, правки и эскалация | `operator.py`, `operator_store.py`, `static/` | Сохранение истории и feedback; отправка остаётся MOCK без боевой интеграции |
| Дедупликация: игрок/проблема/час | `dedup.py`, операторская очередь | Есть кандидаты текстовых дублей; полная межтикетная дедупликация не доказана минимальным контрактом |
| Данные и секреты вне Git | `.gitignore`, `repo_audit.py` | Приватные источники и модели со словарём хранятся локально; аудит доступной истории не заменяет внешний secret scanner |

## Неясности исходного ТЗ

- В описании valid нет category/priority, комментарий схемы упоминает размеченную
  валидацию. Человеческий dev и предварительный assistant-silver имеют разное
  происхождение и не подменяют скрытый тест.
- Пример ответа обещает наказание и просмотр скриншотов вопреки ограничениям.
  Реализация следует ограничениям: жалоба требует проверки, изображения недоступны.
- Интеграция с игрой выполняется организатором после хакатона. Боевой API не
  выдан; наличие локального коннектора не доказывает реальную доставку.
