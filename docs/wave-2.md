# Wave 2 — локальный baseline

Состояние на 30 октября 2026 года. Рабочая копия создана из переданного `project/`
снимка `codex/wave-1` (`1cabc39`). Исходная папка передачи не изменялась.
При реализации состояние удалённых веток не перепроверялось; интеграция в main не выполнялась.

## Что реализовано

- Проверяемая загрузка 14 категорий, четырёх приоритетов и обязательных эскалаций.
  Категории проверяются на уникальность и соответствие kind.
- Индекс всех 266 пунктов из 11 разделов плюс полный текст одного раздела без
  points: 267 источников. Ключ `section_id:ref`; раздел без пунктов — `43:section`.
  Номера не выдумываются, исходные тексты и названия разделов сохраняются.
- Локальный текстовый поиск с весами редкости слов и простыми префиксами,
  максимум пять кандидатов; раскрытие ДМ/GZ/ГЗ/ЗЗ/ЖБ/RMT.
  Поиск выполняется по всем источникам, не по слепо принятым ссылкам категории.
- Разрешение ссылок пользователя и таксономии. `30:2.1` однозначна;
  `2.1` может иметь несколько кандидатов; несуществующие ссылки отмечаются missing.
  GZ обозначает раздел, а не автоматически выбранный пункт.
- Детерминированные лексические категории, приоритет и языковые эвристики.
  Нет вызовов внешних моделей и обучения на ответах администрации.
- Извлечение явно написанного ника формата Name_Surname, номера сервера,
  ссылок и заявленного числа вложений. `has_evidence=false`: изображения не читались.
- Отдельная политика needs_human: аккаунты, платежи, апелляции и персональные
  жалобы передаются человеку; неизвестный язык, слабый контекст и неоднозначные
  ссылки также требуют проверки. Приоритет рассчитывается отдельно.
- Одинаковое ядро для HTTP и CLI. `/health` сообщает mode, draft-версию таксономии
  и SHA-256 источников. Ошибки входа и недоступного справочника возвращаются JSON.
- `draft_available=false`, пустой draft_reply.cited и локализованное уведомление
  об отсутствии черновика. Найденные кандидаты находятся в `retrieved_rules`,
  а неоднозначности — в `reference_resolutions`.

## Измерения

Протокол: `evaluation/protocol.json`; замороженные хеши:
`evaluation/frozen-inputs.json`; локальный воспроизводимый отчёт:
`outputs/wave-2/dev-metrics.json`.

| Показатель | Результат |
|---|---:|
| Dev с человеческими метками и подтверждёнными поправками | 100 |
| Категория, accuracy | 58/100 = 58% |
| Язык, accuracy в текущем контракте | 79/100 = 79% |
| Приоритет, macro-F1 по всем четырём классам | 0.4355 |
| Приоритет, macro-F1 по присутствующим p1/p2/p3 | 0.5806 |
| Обязательная передача по dev-меткам | 65/65, пропусков 0 |
| Всего направлено человеку на dev | 100/100 |
| Лишние передачи относительно dev-меток | 35 |
| Синтетический поиск, hit@5 | 7/7 |
| Синтетический поиск, средняя precision@5 | 0.20 |

Развёрнутый JSON содержит поддержки классов, ошибки классификации по классам,
TP/FP/FN приоритетов и результаты каждого поискового сценария. p0 в dev отсутствует.
Нулевые пропуски достигнуты консервативной передачей всех dev-случаев; это не
доказательство пригодности к автономной обработке. Эти метрики не оценивают
весь рабочий поток: dev мал и отобран с языковым балансированием.

Control не использовался для настройки и не оценивался; проверялся только
хеш файла. Его AI-метки остаются предварительными. Поисковые сценарии созданы
из лексики правил: они проверяют базовое нахождение релевантного источника,
не качество поиска по реальным коротким обращениям. Целостность цитат проверяется
отдельно от релевантности. Все результаты фиксируются без текстов реальных тикетов.

## Проверки

- 109 тестов прошли на Python 3.12.14, включая прежние проверки подготовки данных.
- В составе тестов 34 синтетических сочетания текста и kind для критических
  платежей, аккаунтов, апелляций, угроз и массовых багов. Это не реальные метрики.
- Реальный запуск uvicorn на localhost: health, POST /triage и JSON 422 без
  отражения недопустимых входных полей; результат в `outputs/wave-2/http-check.json`.
- Все 1000 официальных valid inputs обработаны CLI:
  `outputs/wave-2/valid.baseline.jsonl`. Это проверка совместимости, не accuracy.
- pip check: конфликтов нет. Сохранено прежнее предупреждение Starlette TestClient
  о deprecated httpx; текущие проверки проходят.
- Все четыре замороженных источника совпадают с SHA-256 передачи.

## Запуск на Windows

Из папки проекта, PowerShell, Python 3.11+:

```powershell
./run.ps1 -Install
./run.ps1 -Mode Test
./run.ps1 -Mode Evaluate
./run.ps1
```

При необходимости явно указать интерпретатор:
`./run.ps1 -Install -PythonPath C:/path/to/python.exe`.
Скрипт предпочитает доступный bundled Python Codex, иначе `python`.
Установка требует сети, обращения обрабатываются локально.
Swagger: http://127.0.0.1:8000/docs.

```powershell
./run.ps1 -Mode Predict -InputFile examples/synthetic_tickets.jsonl -OutputFile outputs/pred-wave2.jsonl
```

На Linux/macOS сохраняются Makefile и прежние команды. Для независимой оценки:
`python -m support_copilot.evaluate --output outputs/wave-2/dev-metrics.json`.
Оценка откажется работать при несовпадении замороженных источников.

## Ограничения и следующий шаг

Это первый вычисляемый baseline. Лексика не понимает отрицания, цитирование,
сарказм и все искажённые/смешанные формулировки. Общие слова про аккаунт,
платёж, бан или мут могут давать завышенные приоритеты и лишние эскалации.
Синтетические проверки покрывают перечисленные сценарии, не все их перефразы.
Простой поиск по русским источникам слаб для KK/UZ и латиницы.

`confidence` — некалиброванный показатель срабатывания эвристик, не вероятность.
`is_spam_or_duplicate=false` остаётся техническим значением с явной причиной:
межтикетная дедупликация не реализована. Из сообщений reported_player не
выводится намерение заявителя. Сервер и ник — заявленные, не проверенные факты.
Обнаружение RU/KK/UZ и других языков эвристическое; распознаваемый украинский
остаётся `und` с причиной `recognized_uk_outside_contract`, расширение контракта
не выполнялось. Автозамены казахских символов не включались.

Таксономия остаётся draft, таблица замен не подтверждена организаторами.
Генератор, калибровка, семантический поиск, UI-интеграция и качество черновиков
не реализованы. Warm-core p95 в JSON — локальный микрозамер, не производственный
HTTP p95; стоимость инфраструктуры не измерялась. Оплачиваемых вызовов модели нет.

Перед Wave 3 полезно разобрать ошибки на dev и расширить языковые и поисковые
проверки. Для независимых выводов нужна человеческая проверка control или новая
слепая выборка. Генератор должен использовать только существующие релевантные
источники, без обещаний наказания, возврата или разбана.
