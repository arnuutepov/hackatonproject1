# AREA ADMIN PANEL — графитовая тема

Рабочая панель построена на Wave 6. Палитра: фон `#12151B`, поверхность
`#1A1D24`, основной акцент `#FF8800`. Адаптация для GRAND MOBILE использует
отдельно нарисованный знак прототипа, системные шрифты и локальные SVG-иконки.
Игровые ресурсы и сторонние шрифты не загружаются.

## Сценарии

- Reports: общая таблица обращений. Поиск, фильтры статуса/приоритета/языка,
  сортировка по дате или приоритету, страницы по 10 строк.
- Applications: запросы канала `report` (помощь, платежи, вопросы), без жалоб
  канала `complaint`. Это запросы поддержки, не заявки на вступление в команду.
- Dashboard: счётчики и распределение реальной локальной очереди.
- Players: никнеймы, извлечённые анализатором, с переходом к обращениям.
  Упоминание не приписывается автоматически заявителю или нарушителю.
- Server Logs: локальный журнал последних 50 обновлённых обращений,
  до 150 событий. Игровые серверные логи не подключены.
- Settings: компактность строк и отключение анимаций, сохранённые в браузере.
  Системный `prefers-reduced-motion` также поддержан.

Карточка справа содержит исходные сообщения, сведения о вложениях, локальное
время создания записи, извлечённый контекст, правила, редактируемый черновик,
заметки и историю. Исходные игровые timestamps и изображения не выдумываются.
Вложения не загружаются, их количество не означает просмотр доказательств.

С версии 0.9.0 Quick Take сохраняет ID вошедшего оператора. Назначение другого
сотрудника может изменить только lead/admin. `local_operator` остаётся лишь в
явном loopback-режиме разработки `COPILOT_AUTH_MODE=local`.
Resolve сохраняет локальный статус `resolved`, когда анализ выполнен и нет
обязательной ручной проверки. Эскалацию может завершить lead/admin после ручной
проверки с обязательным комментарием; анализ остаётся неизменным, факт проверки
и автор сохраняются отдельно. Reopen возвращает обращение в работу.
BAN и MUTE открывают объяснение недоступной интеграции; endpoints санкций нет.
Log Out отзывает серверную сессию и удаляет cookie. Роли и защита всех маршрутов:
[security.md](security.md).

## Разделение ответственности

| Файл | Ответственность |
|---|---|
| `static/index.html` | Семантическая структура, формы и доступные названия |
| `static/workspace.css` | Палитра, сетка, адаптация и переходы |
| `static/api-client.js` | Same-origin HTTP, таймауты, безопасные ошибки |
| `static/workspace.js` | Карточка, анализ, черновик, сравнение и сохранение |
| `static/admin-views.js` | Таблица, навигация, фильтры, сводка, drawer, настройки |
| `operator.py`, `security.py` | Контракты API, сессии/роли, обязательный Origin и защита по умолчанию |
| `operator_store.py` | SQLite, назначения, ревизии, история и переходы статуса |
| `service.py` | Неизменённое ядро анализа и политики ответа |

Скрипты подключаются в явном порядке: транспорт, контроллер, представления.
Данные из API выводятся через `textContent`, а не HTML. CSP продолжает запрещать
inline-скрипты и внешние подключения. Интерфейс не получает ключ модели.

Назначения хранятся в новой таблице `assignments`; существующие записи и события
не переписываются. Каждая операция проверяет `expected_revision` внутри
`BEGIN IMMEDIATE`. Изменение назначения и статуса атомарно добавляет событие.

Новый маршрут:

```text
POST /operator/tickets/{uuid}/workflow
{"expected_revision": 2, "action": "take"}
```

Действия: `take`, `release`, `resolve`, `reopen`. Клиент не может передать
собственный `needs_human`, обойти политику или выполнить `ban`/`mute`.

## Проверки 30 октября 2026

- 277 Python-тестов прошли на Windows, включая 8 новых проверок назначения,
  конкурентной записи, завершения/повторного открытия и обязательной эскалации.
- DOM-интеграционная проверка с настоящим API на отдельной временной SQLite-базе:
  поиск, назначение, анализ, редактирование/сохранение/обновление, завершение,
  навигация по шести разделам, настройки, журнал, платёжная эскалация,
  объяснение BAN, пауза/возобновление. Ошибок DOM-контроллера не обнаружено.
- Проверена загрузка локальных ресурсов и отсутствие конфликтующих HTML ID.
- DOM-проверка не измеряет раскладку CSS. Управление Comet было заблокировано
  инструментом даже после пользовательского разрешения. Визуальная проверка
  desktop/mobile не завершена, скриншот результата не заявляется.

Запуск остаётся прежним: `./run.ps1`, затем http://127.0.0.1:8000/.
Данные, база и диагностические результаты остаются вне Git.
