## Найденные и исправленные ошибки

Обе ошибки обнаружены на новых синтетических примерах Wave 7, а не на control.

1. **«Игра вылетает» считалась читерством.** Шаблон `cheat` содержал подстроку
   `летает`, которая входит в слово «вылетает». Обращение о вылете игры получало
   `report.complaint` и p1. Теперь `(?<!вы)летает`: результат `report.help` и p2.
   Жалоба «игрок летает» по-прежнему распознаётся как `complaint.cheat`.
2. **Номер сервера не извлекался из «на сервере 4».** Выражение принимало только
   форму «сервер». Теперь учитываются формы «сервера/сервере/серверу/сервером»
   и в извлечении, и в проверке противоречий между сообщениями.

На Linux после этих правок выполнен `make measure` на прежних 100 control-обращениях.
Хеши обоих справочников, dev и control совпали с `evaluation/frozen-inputs.json`.
Категории: 57/100; язык: 67/100; macro-F1 приоритета: 0.5324 по всем классам,
0.7099 по присутствующим. Передача человеку: 100/100; обязательных передач 69,
пропусков 0, дополнительных передач 31. Метрики совпали с Wave 5.
Это прежняя silver-выборка с метками ассистента, независимой оценкой она не стала.

Задержка измерена последовательными запросами к localhost в шаблонном режиме:
это не нагрузочный тест, не WAN и не вызов живой модели. Совпадение HTTP/CLI и
инварианты проверяются на первом проходе 20 примеров; три прохода используются
для задержки и проверки HTTP-статуса. API модели: 0 вызовов, $0.

Исправлен аудит: прежнее исключение маркера пропускало всю строку вместе с
возможным другим ключом. Теперь исключается ровно совпавший токен; отчёт выводит
только коммит, путь и номер строки, не содержимое ключа. Ошибка `git grep`
останавливает аудит вместо ложного успеха. Три теста проверяют точное исключение,
другой ключ на той же строке и ключ с маркером в качестве префикса.

Осталось предупреждение Starlette о deprecated-интеграции TestClient с httpx;
тесты проходят на зафиксированных зависимостях. macOS, Windows, живой провайдер,
независимая оценка языков и браузерная проверка интерфейса в этот прогон не входят.

## Как повторить проверку на машине команды

```bash
git clone --branch claude/wave-7 https://github.com/BAITC-Hacks/hack-a4a36997-oguzki.git oguzki-wave7
cd oguzki-wave7
# положить rules.json и taxonomy.json в data/handout-2026-10-27/
make install
COPILOT_DRAFT_PROVIDER=template make check
```

`make check` = `make test` → `eval-regressions` → `eval-drafts` →
`submission-check` → `audit-repo`. Любой сбой останавливает цепочку с ненулевым
кодом. Отчёты: `outputs/wave-7/submission-check.json` и `outputs/wave-7/demo.md`.
Windows: `./run.ps1 -Install`, затем режимы `Test`, `RegressionEvaluate`,
`DraftEvaluate`, `SubmissionCheck`, `AuditRepo`.

## Ограничения, которые остаются

- Классификатор лексический: на silver-control 57% по категориям (Wave 5).
  Метки control подготовлены ассистентом, это не слепой тест.
- Все 100% обращений control передаются человеку. Автономной пропускной
  способности нет: система — помощник оператора, а не автоответчик.
- Справочника ответов FAQ нет, поэтому на игровые вопросы сервис честно не отвечает.
- Живая модель, её стоимость (цель $0.002) и p95 не измерены: провайдер выключен.
  Стоимость $0 относится только к API модели в шаблонном режиме.
- Независимая человеческая оценка черновиков и языков KK/UZ не проведена.
  В control один пример KK.
- Межтикетная дедупликация не реализована: `is_spam_or_duplicate=false`.
- Вложения не просматриваются. Доставки в игру и аутентификации операторов нет.
  Сервис — локальный MVP, не публичный.
