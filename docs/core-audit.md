## Исправленные пробелы

- Серверный маршрут чата жёстко требовал Capybara и отклонял Gemini. Теперь
  выбор провайдера общий для конфигурации, чата и черновиков; шаблонный режим
  не использует оставшиеся в окружении ключи другого провайдера.
- Панель отличает «настроен, связь не проверена» от успешного проверочного
  запроса. Кнопка «Проверить связь с ИИ» отправляет только рукописный тестовый
  платёжный вопрос. Она проверяет не только HTTP-ответ, но и валидность плана.
- Gemini считает токены полного запроса через `countTokens`: системная
  инструкция, схема и сообщения включены. Перед `generateContent` проверяется
  стоимость входа + запас 512 токенов + максимум 900 выходных токенов.
  Бюджет по умолчанию $0.002 можно только уменьшить. Неизвестная цена или
  недоступный счётчик блокируют генерацию, повторных платных попыток нет.
- Ошибки ключа/доступа, квоты, отсутствующей модели, времени ожидания и бюджета
  имеют отдельные коды. Исходные ответы с секретами и тексты запросов не логируются.
- Нарушения Non RP относятся к `complaint.dm` согласно загруженной таксономии.
  Администратор в формулировках «в присутствии» и «на глазах у» учитывается
  как свидетель; отдельная жалоба на администратора сохраняется.
- Для ограниченного набора русскоязычных жалоб шаблон может цитировать точное
  запрещающее предложение из проверенного справочника. ID, совпадение текста,
  тема и релевантность проверяются тем же валидатором, что у модельного плана.
  Изменившийся справочник, неверная ссылка, риск или неподходящая цитата
  возвращают безопасный шаблон. Цитата — основание для проверки человеком,
  а не установление нарушения; число вложений не служит доказательством.
- Добавлена общая офлайн-команда измерений с baseline, разбивками и JSON/Markdown.
  Она не выполняет инференс по control и использует отдельную временную SQLite.
  `model_on_check` использует выбранного провайдера вместо фиксированного Capybara.

## Как воспроизвести

После установки зависимостей и размещения разрешённых правил/таксономии:

```bash
python -m support_copilot.project_metrics --http --passes 10 --workers 4 --output outputs/core-audit/final
python -m pytest -q
```

GNU Make: `make project-metrics`. Windows: `./run.ps1 -Mode Metrics`.
Без приватного dev: добавьте `--no-dev` (классификационная accuracy будет `null`).
Control проверяется только по зафиксированным SHA-256, не используется для
новой настройки или инференса этой командой. Без справочников сервис не запустится.

## Gemini и замена ключа

Windows после создания venv:

```powershell
.\start-model.ps1
```

Скрипт запрашивает ключ скрытым вводом и слушает `127.0.0.1:8001`. Ключ не
пишется в Git или браузер. При наличии собственной переменной окружения либо
`GEMINI_API_KEY_FILE` используется она; для другого venv есть `-EnvironmentPath`.
Новый ключ можно ввести при следующем запуске. Настройки родительского PowerShell
восстанавливаются после завершения сервера. Старый процесс нужно остановить
Ctrl+C перед запуском обновлённого кода.

Переносимая конфигурация: `COPILOT_DRAFT_PROVIDER=gemini`, `GEMINI_API_KEY`
(или `GEMINI_API_KEY_FILE`), `COPILOT_GEMINI_MODEL=gemini-2.5-flash-lite`.
`.env` автоматически не загружается. У другого провайдера могут отличаться
endpoint, формат запросов и схема авторизации: замены одного ключа недостаточно.

```bash
python -m support_copilot.ai_runtime          # только настройка, без сети
python -m support_copilot.ai_runtime --check  # один синтетический платный план
python -m support_copilot.model_on_check --allow-paid-synthetic --output outputs/model-check
```

Шесть model-on сценариев синтетические; эта команда не отправляет датасет.
В отчёте успешные планы и fallback считаются отдельно; timeout не записывается
как бесплатный запрос. Включение ключа не доказывает качество и не меняет
категориальный backend: Gemini создаёт план черновика и совет оператору.

Тариф Gemini 2.5 Flash-Lite взят из [официального прайса Google](https://ai.google.dev/gemini-api/docs/pricing):
$0.10 / миллион входных и $0.40 / миллион выходных токенов, проверено 31.10.2026.
Предварительный счётчик использует [полный GenerateContentRequest](https://ai.google.dev/api/tokens).
Расчёт не учитывает скидку за кеш, инструменты выключены, thinking выключен
для модели по умолчанию. Для другой модели нужен проверенный `COPILOT_PRICING_FILE`.
Бюджет — технический фильтр по сохранённому тарифу и ответу countTokens;
изменение тарифов, погрешность токенизации и фактическое списание проверяются
отдельно. Полного лимита расходов аккаунта этот фильтр не заменяет.
