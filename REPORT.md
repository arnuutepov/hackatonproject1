# Отчёт о качестве Oguzki Support Copilot

Этот отчёт различает проверенные числа, исторические измерения и то, что ещё
не измерено. Модель категорий экспериментальная; по умолчанию используются правила.

## Текущая проверка правил на dev

31 октября 2026, template, backend `rules`, 100 ранее размеченных человеком
dev-обращений. Dev использовался для настройки, это **не независимая оценка**.
Bootstrap по кейсам, 2000 повторов, seed 20261031. Сырые результаты и обращения
остаются локально в игнорируемом `outputs/jury-readiness/`.

| Показатель | Значение | 95% CI |
|---|---:|---:|
| Категория, accuracy | 71/100 = 71% | 62–80% |
| Язык, accuracy | 94/100 = 94% | 89–98% |
| Приоритет, accuracy | 81/100 = 81% | 73–89% |
| Категория, macro-F1 по всем классам | 0,4122 | не рассчитан |
| Обязательная передача человеку по dev-меткам | 65/65, пропущено 0 | не рассчитан |
| Доля needs_human | 100/100 | не рассчитан |
| Precision эскалации | 65/100 = 65% | не рассчитан |

Baseline «всегда передавать человеку» на этих же метках: recall 65/65,
precision 65/100, доля автоматизации 0% — как и у текущих правил на dev.
Требование **категория выше 85% пока не достигнуто** даже на dev; 94% по языку
нельзя переносить на новые данные. На независимом human gold метрики ещё не
получены. Control заморожен и в этом прогоне для инференса не использовался.

Разбор 29 ошибок категорий на том же dev: 7 — `complaint.insult` →
`complaint.invalid`, 4 — `complaint.other` → `complaint.invalid`, по 3 —
`complaint.dm` → `complaint.other`, `complaint.admin` → `complaint.other` и
`report.complaint` → `report.offtopic`. Первые семь содержат очень короткий
текст неопределённого языка и сведения о вложениях; сами изображения недоступны
для анализа. Количество вложений не устанавливает тип нарушения. Нужно отдельно
проверить происхождение меток и доступность изображений при разметке; угадывать
категорию по вложениям нельзя. Это разбор dev, не новая независимая оценка.

## Демонстрация и проверки

Рукописные обращения — `examples/wave7_demo.jsonl`. Пять сценариев описаны в
`docs/wave-7.md`: вопрос, жалоба, казахский, платёж и неправильная ссылка.
Полный совместный прогон на Windows: **685 passed, 1 skipped**; отдельно
регрессии 270/270 и проверки черновиков 133/133. Это проверки работы и
безопасности, не accuracy модели. Исправлены зависимость теста OIDC от времени
сбора и чтение UTF-8 журнала в тесте коннектора под Windows.

Добавлен один узкий кандидат без эскалации: точный общий вопрос по-русски о
допустимости оскорблений игроков (две формулировки). Ответ цитирует точное
предложение из правила `30:2.1`, только при совпадении SHA-256 справочника и
прохождении проверки релевантности. Вложения, другие сообщения, флаги риска,
подмена инструкций, изменение справочника или отсутствие шаблона возвращают
случай человеку. Это ответ на общий вопрос, не решение по жалобе и не отправка.
Два положительных и дополнительные отрицательные синтетические примеры проверены;
в dev доля эскалаций осталась 100%, измеренной разгрузки пока нет.

## Стоимость и задержка

Template: вызовов внешней модели нет, API-расход $0; CPU/хостинг не измерены.
Чистый локальный клон коммита `8a91e48` с новым venv на Windows и пакетами из
`requirements-dev.lock`: 5 синтетических кейсов, 15 последовательных localhost
HTTP-запросов, p50 5,91 мс, p95 28,28 мс (nearest rank), HTTP и CLI совпали
5/5, узкий вопрос дополнительно проверен по HTTP, вызовов модели 0. Команда
Windows `run.ps1 -Mode Predict` создала пять ответов; `pip check` без конфликтов.
Это smoke, не нагрузочное или независимое измерение; команды `make` и
Linux/macOS README в этом прогоне не выполнены.
Исторический load p95 148,57 мс — 300 localhost-запросов, 8 клиентов на другой
версии, не производственный SLA. Живая модель после этих правок не проверялась:
ключ не предоставлен. Её стоимость, p50/p95, успешность и соответствие цели
$0,002 на обращение неизвестны. Прежний прогон другой конфигурации модели
имел 0/6 валидных планов и 6/6 fallback; причины необходимо измерить отдельно.

## Ограничения и следующий шаг

- Независимые человеческие метки ещё ожидаются. Текущий silver-control имеет
  метки ассистента; старые 77% языка на нём относятся к прежней версии.
- Пакет из 40 обращений подготовлен локально для двух независимых рецензентов;
  совпадение по игрокам и отсутствие перефразированных дублей не подтверждены.
- Базы готовых ответов на вопросы нет, кроме одного узкого кандидата выше. Не
  отключать обязательную эскалацию и не цитировать найденные правила без проверки.
- Необходимо получить ключ для малого синтетического model-on прогона, затем
  согласовать цены и оценить задержку/usage. Приватные обращения во внешний
  провайдер без отдельного согласования не отправляются.
- Повторно не настраивать по frozen control. Обучение возможно только на новых
  разрешённых человеческих метках с разделением train/validation/test по группам.
