# Проверка пакета перед сдачей

Пакет проверен 31 октября 2026 на Windows / Python 3.12.14 в отдельной копии:

- Создан **новый venv**, зависимости скачаны и установлены по requirements-dev.lock.
- `quickstart.ps1 -SetupOnly` скопировал только два справочника и загрузил 267
  пунктов правил / 14 категорий. Датасет, логин и API-ключ для проверки не требовались.
- `test-mvp.ps1` выполнен через Windows PowerShell (`powershell.exe`), как в
  ярлыке TEST-MVP.cmd. Завершился PASS: HTTP/CLI, черновики и безопасность.
- Пакетный запуск на `examples/submission-demo.jsonl` записал **8 ответов**.
  RU/KK/UZ определились в предусмотренных демонстрационных сценариях;
  платежи и аккаунт потребовали человека, отсутствующее правило не было придумано.
- Скрипты запуска прошли синтаксическую проверку. Интерактивный ввод собственного
  пароля/ключа выполняет пользователь; живой Google API в этом прогоне не вызывался.

В ZIP в папке `verification/` сохранены JSON и Markdown этой офлайн-проверки.
Они относятся к синтетическим примерам и не являются независимой оценкой
accuracy на реальных обращениях. Измерения dev и границы — в ОТЧЁТ-ДЛЯ-СДАЧИ.md.

Архив не содержит Python/venv, данных, правил организаторов, API-ключей,
операторских паролей, SQLite или Git-истории. Это позволяет проверяющему
установить окружение и подключить собственные разрешённые источники и ключ.
